# Kashi Code Collective website

Jekyll site (GitHub Pages compatible).

## Run locally

    bundle install
    bundle exec jekyll serve

Then open http://localhost:4000.

## Editing

- Home page: `index.html`
- Nav links: `_data/navigation.yml`
- Projects: `_data/projects.yml` (`featured: true` shows on the home page)
- Pages: `projects.md`, `social.md`, `campus.md`, `join.md`
- News: add `_posts/YYYY-MM-DD-title.md`
- Styles: `assets/css/style.css`
